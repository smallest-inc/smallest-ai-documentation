# Generated Waves contracts

`openapi.json` and `asyncapi.json` are generated by `waves-platform/apps/main-backend` from the
runtime Zod schemas. Do not edit them here.

To refresh a local checkout:

```bash
python3 scripts/sync_waves_api_contracts.py
```

Fern override files remain documentation-owned. They add examples, guides, SDK method names, and
audience metadata without redefining wire-level request or response shapes.
