The Platform API allows you to manage agents, calls, campaigns, knowledge bases, and more programmatically.

## The Atoms Client

The `SmallestAI` client is the main entry point for interacting with the Smallest.ai Platform API. It wraps all specific API groups (Agents, Calls, etc.) into a single, cohesive interface under `client.atoms`.

### Initialization

```python
from smallestai import SmallestAI

# Initialize the client (picks up SMALLEST_API_KEY from environment)
client = SmallestAI()
```

### Accessing APIs

You can access specific functionality through the resource groups on `client.atoms`:

```python
# Create an agent
client.atoms.agents.create_agent(name="my-agent")

# Managing Knowledge Bases
client.atoms.knowledge_base.list()

# Checking Calls
client.atoms.calls.get(id="call_id")
```
