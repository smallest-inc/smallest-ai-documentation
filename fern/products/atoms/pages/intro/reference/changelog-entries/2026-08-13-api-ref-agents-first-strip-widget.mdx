---
title: "Voice Agents API reference: Agents-first ordering, widget endpoints removed"
---

The API reference sidebar now opens with **Agents** at the top, followed by **Calls**, **Campaigns**, **Phone Numbers**, and **Knowledge Base**. User, Account, and Billing sit at the bottom. Matches the ordering pattern used by every peer voice-AI reference (Vapi, Retell, Bland, Deepgram Voice Agent, ElevenLabs Conversational AI). No URL slugs changed; only the sidebar ordering.

Three widget-only endpoints are removed from the API reference:

- `GET /agent/{id}/widget-config`
- `PATCH /agent/{id}/widget-config`
- `POST /agent/{id}/avatar/presigned-url`

These control the embeddable chat widget and its avatar image. The chat widget is configured from the dashboard; the endpoints are not part of the customer-facing REST surface. The `widgetConfig` object on the agent response body is unchanged (safe to ignore for API-only integrations).
