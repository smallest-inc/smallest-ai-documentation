---
title: "CLI: live call events + build logs + `waves` → `models` rename (SDK 5.11.0)"
---

`smallestai>=5.11.0` adds two live-observability streams and renames the speech command group.

**Live call events.** `smallestai calls events <call-id>` streams a running call's transcript turns, per-turn latency, node transitions, tool calls, and errors. `smallestai calls transcript <call-id> --follow` filters that stream down to just the conversation turns. Both require an in-progress call and a CLI session (`smallestai auth login`). Add `--json` on `calls events` to emit one raw event per line.

**Crew build logs.** `smallestai agent-crew logs [build-id]` tails a build's compile + deploy logs; defaults to the latest build for the linked agent.

**Group rename: `waves` → `models`.** The speech command group is now `smallestai models` (text-to-speech, speech-to-text, voices). `waves` still works as a hidden, back-compatible alias; existing scripts keep running. Use `models` as the canonical name in new code.

Full command reference: [Agents CLI](/voice-agents/developer-guide/get-started/agents-cli). Summary of all groups: [Client Libraries overview](/voice-agents/developer-guide/client-libraries).
