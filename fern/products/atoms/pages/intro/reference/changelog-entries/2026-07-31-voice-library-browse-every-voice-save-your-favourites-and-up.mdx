The new Voice Library gives you one place to explore all available voices. Browse featured picks and the full catalogue in a searchable, filterable table (by use case, language, accent, gender, and model), preview any voice on hover, and upvote the ones you like. Save voices to **My Library** for quick access, and jump straight into the TTS playground with any voice using **Use**. The voice picker inside the studio has been redesigned to match, with the same search, filters, and All Voices / My Library tabs.
