---
title: "New docs: smallestai agents CLI + How agent-crew works"
---

Two new pages under **Developer → Get Started**.

**Agents CLI reference.** All six commands under `smallestai agents` (`create`, `list`, `get`, `dashboard`, `phone-status`, `call`), with argument and option tables, an end-to-end example, and the `SMALLEST_API_KEY` / `SMALLEST_BASE_URL` env-var contract. All commands verified against `api.smallest.ai` on `smallestai==5.3.0`, including a real outbound call that reached the destination and completed successfully.

**How agent-crew works.** The full lifecycle from create to live call, the crew/node/crew-code term model, and the two-axes versioning model:

| Axis | What | Managed by | Versioned as |
|---|---|---|---|
| Config | prompt, voice, language, STT/TTS, model, tools | dashboard or versioning API | branches + revisions |
| Crew code | your Python that produces the LLM response | `agent-crew` CLI | builds |

Includes a verified end-to-end sample (server.py + assistant.py + requirements.txt) and a six-item FAQ that spells out the "agent-crew links to an existing agent, it does not create one" correction.

Both pages sit next to the existing **Quickstart Crew CLI** so new SDK users can get from install to first call, then to the mental model of how the platform manages agents around their code.
