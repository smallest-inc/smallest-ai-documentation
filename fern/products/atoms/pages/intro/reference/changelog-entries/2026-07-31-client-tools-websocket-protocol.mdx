---
title: Client tools now documented in the Realtime Agent WebSocket API
---

The wire protocol for client tools is now in the Atoms Agent WebSocket spec. `session.update` (previously a reserved no-op) declares runtime client tools, plus new `session.updated`, `function_call`, and `function_call.result` messages, timeout and 64 KB result-size limits, and the client-tool error codes (`tool_name_conflict`, `client_tools_managed_by_config`, `invalid_tools`, `tool_timeout`, `unknown_call_id`, `result_too_large`).
