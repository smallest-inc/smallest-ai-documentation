The Atoms docs are deep. This page is the shortest path from "I want X" to the one canonical page covering X. Built for forward-deployed engineers and customers who need an answer in one click.

## Choose your starting point

Two surfaces exist for building agents. Pick by interface, not by complexity.

| If you want to... | Start here |
|---|---|
| Build an agent **without writing code** - single prompt, voice picker, dashboard config | [Atoms Platform Quick start](/voice-agents/quickstart) |
| Build an agent **in Python**, multi-node, custom logic, custom LLM | [Quickstart Crew CLI](/voice-agents/developer-guide/get-started/quickstart) |
| Understand the **crew lifecycle** and versioning (config vs builds) | [SDK overview](/voice-agents/developer-guide/get-started/overview) |
| Manage agents **from the terminal** (create, list, dashboard, call) | [Agents CLI](/voice-agents/developer-guide/get-started/agents-cli) |
| Embed an agent in a **web page** (existing agent) | [Agent Web SDK](/voice-agents/integrate/web-socket-sdk) |
| Embed an agent in a **mobile app** | [React Native](/voice-agents/integrate/mobile/react-native) · [iOS Swift](/voice-agents/integrate/mobile/i-os-swift) · [Android Kotlin](/voice-agents/integrate/mobile/android-kotlin) · [Flutter](/voice-agents/integrate/mobile/flutter) |
