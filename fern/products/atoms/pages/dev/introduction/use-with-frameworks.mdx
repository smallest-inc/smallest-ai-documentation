title: Use with pipecat & LiveKit
subtitle: Reach the framework-native Smallest AI plugins from the SDK namespace.
description: "Use Smallest AI speech services inside pipecat or LiveKit Agents through smallestai.integrations, installed as optional extras."
---

If you build voice agents with [pipecat](https://github.com/pipecat-ai/pipecat) or
[LiveKit Agents](https://github.com/livekit/agents), you can reach the framework-native
Smallest AI plugins from the `smallestai` namespace. The frameworks are **optional
extras**: the core SDK does not depend on them, and each adapter imports its framework
only on first use.

## pipecat

```bash
pip install "smallestai[pipecat]"
```

```python
from smallestai.integrations.pipecat import SmallestSTTService, SmallestTTSService
```

These forward to `pipecat.services.smallest`, so every option the plugin supports is
available. Use them like any other pipecat service in your pipeline. pipecat requires
Python 3.11+.

## LiveKit

```bash
pip install "smallestai[livekit]"
```

```python
from smallestai.integrations.livekit import TTS
```

This forwards to `livekit.plugins.smallestai`. LiveKit Agents requires Python 3.10+.

## If the extra isn't installed

Importing the adapter module never fails on its own. Using a name from it without the
extra installed raises a clear error telling you which extra to install, for example:

```
ImportError: The pipecat integration requires pipecat-ai. Install it with:
    pip install "smallestai[pipecat]"
```
