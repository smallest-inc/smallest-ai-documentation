The Real-Time Pulse STT WebSocket API supports the following features:

## Available Features

<CardGroup cols={2}>
  <Card title="Word Timestamps" icon="clock" href="/models/speech-to-text/features/word-timestamps">
    Get precise timing information for each word in the transcription with confidence scores
  </Card>
  <Card title="Language Detection" icon="language" href="/models/speech-to-text/features/language-detection">
    Automatically detect the language of the audio
  </Card>
  <Card title="Sentence Timestamps (Utterances)" icon="comment-dots" href="/models/speech-to-text/features/utterances">
    Get sentence-level transcription segments with timing information
  </Card>
  <Card title="PII & PCI Redaction" icon="eye-slash" href="/models/speech-to-text/features/redaction">
    Automatically redact personally identifiable information and payment card information
  </Card>
  <Card title="Speaker Diarization" icon="users" href="/models/speech-to-text/features/diarization">
    Identify and label different speakers in the audio with speaker confidence scores
  </Card>
  <Card title="Keyword Boosting" icon="arrow-up-right-dots" href="/models/speech-to-text/features/keyword-boosting">
    Boost recognition accuracy for specific words, brand names, and domain terms
  </Card>
  <Card title="Punctuation Formatting" icon="font" href="/models/speech-to-text/features/punctuation-formatting">
    Control punctuation and capitalization formatting in transcripts
  </Card>
  <Card title="End-of-Utterance Timeout" icon="clock-rotate-left" href="/models/speech-to-text/features/end-of-utterance-timeout">
    Control how long Pulse waits after speech ends before finalizing the transcript
  </Card>
  <Card title="Inverse Text Normalization" icon="spell-check" href="/models/speech-to-text/features/inverse-text-normalization">
    Convert spoken-form numbers, dates, and currencies into written form
  </Card>
  <Card title="Finalize Control" icon="flag-checkered" href="/models/speech-to-text/features/finalize-control">
    Take manual control of when transcripts are finalized using `finalize_on_words` and `max_words`
  </Card>
  <Card title="VAD Events" icon="wave-square" href="/models/speech-to-text/features/vad-events">
    Emit acoustic `speech_started` / `speech_ended` frames interleaved with the transcription stream. Independent of transcript finalization.
  </Card>
  <Card title="Endpointing" icon="stopwatch" href="/models/speech-to-text/features/endpointing">
    Tune the end-of-utterance silence timeout with `eou_timeout_ms` for interactive vs dictation-style workloads.
  </Card>
  <Card title="Age & Gender Detection" icon="user-tag" href="/models/speech-to-text/features/gender-detection">
    Optional per-speaker age and gender inference alongside the transcript.
  </Card>
  <Card title="Emotion Detection" icon="face-smile" href="/models/speech-to-text/features/emotion-detection">
    Optional per-utterance emotion classification alongside the transcript.
  </Card>
</CardGroup>
