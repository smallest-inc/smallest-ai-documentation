Your bill has two components: **software** (Smallest AI, via AWS Marketplace) and **infrastructure** (SageMaker instance-hours). Both land on your normal AWS invoice.

## Software rate

The listing charges a **per-hour software rate per running instance**. It bills for the wall-clock time an endpoint stays `InService`, not for the number of requests served.

## Infrastructure rate

AWS bills you separately for the SageMaker Real-time inference instance. Rates are set by AWS, published on the [SageMaker pricing page](https://aws.amazon.com/sagemaker/pricing/), and vary by region.

Typical instance rates in `us-east-1` for reference (verify on the AWS pricing page before quoting):

| Instance | On-demand rate | Notes |
|---|---|---|
| `ml.g5.xlarge` | ~$1.41/hour | Lightning v3.1 recommended baseline. |
| `ml.g5.2xlarge` | ~$1.69/hour | Pulse recommended baseline. |
| `ml.g5.4xlarge` | ~$2.72/hour | Higher throughput per instance. |

**Savings Plans** and **Reserved Instances** apply the same way as any other SageMaker workload; a 1-year no-upfront commitment usually knocks 30-40% off the on-demand rate.

## Free trial

The listing includes a **14-day free software trial**. During the trial, the Smallest AI portion is $0. **AWS infrastructure charges still apply.** An endpoint left running for the full trial on `ml.g5.xlarge` costs roughly $475 in AWS instance-hours alone.

The trial starts when you accept the EULA, not when you first create an endpoint. Delete endpoints you're not using between trial and paid periods to keep the infrastructure bill honest.

## Private offers

For volume, longer commit terms, or non-standard EULA edits, contact `support@smallest.ai` with:

- Target monthly instance-hours
- Preferred commit length (1 or 3 years)
- AWS account IDs to grant the private offer to

Private offers land in the [AWS Marketplace Private Offers](https://console.aws.amazon.com/marketplace/home?#/private-offers) console; accept there and Terraform / the console handle the rest transparently.

## Estimating a month

The formula:

```
monthly_cost = (software_rate + instance_rate) × 24 × 30 × instance_count
```

## Version upgrades

Each pinned software version has its own published rate. Upgrading in place (create a new endpoint config pointing at the new version's Product ARN, then update the endpoint) may change the software rate. Marketplace displays the new rate before you commit.

## What you are NOT billed for

- **Marketplace subscription itself:** zero cost when no endpoint is running.
- **`sagemaker:InvokeEndpoint` calls:** counted against the software + instance rate above, not billed per call.
- **CloudWatch metrics:** free at default granularity; custom metrics or detailed monitoring bill separately per AWS's normal CloudWatch rates.
