Pulse Speech-to-Text is available as an Amazon SageMaker model package on AWS Marketplace. Once subscribed, you deploy an endpoint inside your own VPC; transcription traffic stays in your AWS account, and AWS bills you directly for the software (per instance-hour) and the underlying compute.

**Marketplace listing:** [Smallest AI Pulse Speech-to-Text Streaming (English)](https://aws.amazon.com/marketplace/pp/prodview-tf5i65efzgtco). Current version: `20260902-14`.

## What the model does

Same Pulse behaviour as the cloud API, hosted inside your account:

- Real-time streaming transcription with sub-100 ms time-to-first-token on a warm endpoint.
- Pre-recorded batch transcription for offline audio.
- Automatic language detection and mid-stream code-switching.
- Speaker diarization, sentence-level timestamps, keyword boosting.
- Noise-robust transcription for call-center and conversational audio.
- PII and PCI redaction, punctuation, inverse text normalisation on by default.

For the option surface (every request-level flag Pulse accepts), see the [Pulse feature reference](/models/documentation/speech-to-text-pulse/features/word-timestamps). Languages match the [Pulse model card](/models/model-cards/speech-to-text/pulse) exactly.

## When SageMaker is the right fit

- **Regulated workloads.** Endpoints run inside your VPC and inherit your existing AWS compliance posture (HIPAA-eligible, SOC, ISO, PCI, FedRAMP where the region supports it).
- **You already run on AWS.** Native integration with CloudWatch, IAM, VPC endpoints, PrivateLink, KMS, CloudTrail, and Application Auto Scaling.
- **Consolidated billing.** Software charges land on your AWS Marketplace bill; no separate Smallest AI invoice.
- **Minimal operational overhead.** AWS owns the container runtime, patching, and health checks. You own the endpoint config.

## When Docker or Kubernetes is a better fit

- **Non-AWS deployments.** Bare-metal, on-prem, or another cloud. See the [Docker](/models/self-host/docker-setup/stt-deployment/quick-start) or [Kubernetes](/models/self-host/kubernetes-setup/quick-start) guides.
- **You need to swap tokenizers, patch models, or add middleware inside the runtime.** SageMaker locks you to the container image published to Marketplace. Docker is the fit for custom internals.

## Regions

Available in every AWS region that supports the `ml.g5.*` instance family. Confirm on the [SageMaker instance-type pricing page](https://aws.amazon.com/sagemaker/pricing/) before you subscribe.
