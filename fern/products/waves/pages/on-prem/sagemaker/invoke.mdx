## Authentication

SageMaker endpoints are authenticated with **AWS Signature Version 4** using your IAM credentials. There is no `SMALLEST_API_KEY` on this path. The caller needs `sagemaker:InvokeEndpoint` on the endpoint ARN (plus the streaming variant if you use streaming).

Minimal IAM policy:

```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "sagemaker:InvokeEndpoint",
      "sagemaker:InvokeEndpointWithResponseStream"
    ],
    "Resource": "arn:aws:sagemaker:REGION:ACCOUNT_ID:endpoint/ENDPOINT_NAME"
  }]
}
```

## Pulse options

Every option Pulse accepts on the cloud API is available on SageMaker. The transport differs (SageMaker payload vs cloud query params or JSON body), but the field names are the same. For the full list, see the [Pulse feature reference](/models/documentation/speech-to-text-pulse/features/word-timestamps).

Common flags: `language`, `diarize`, `punctuate`, `word_timestamps`, `utterances`, `redact_pii`, `redact_pci`.

## Observability

The endpoint publishes standard SageMaker CloudWatch metrics automatically:

| Metric | Namespace | Meaning |
|---|---|---|
| `Invocations` | `AWS/SageMaker` | Requests per minute |
| `ModelLatency` | `AWS/SageMaker` | Time inside the container |
| `OverheadLatency` | `AWS/SageMaker` | SageMaker overhead per request |
| `CPUUtilization` | `/aws/sagemaker/Endpoints` | Container CPU |
| `GPUUtilization` | `/aws/sagemaker/Endpoints` | Container GPU |
| `MemoryUtilization` | `/aws/sagemaker/Endpoints` | Container RAM |

Container stderr and stdout land in CloudWatch Logs under `/aws/sagemaker/Endpoints/<endpoint-name>`. Screenshots of a useful log filter live on the [Troubleshooting](/models/self-host/amazon-sagemaker/troubleshooting) page.
