---
title: "Voice cloning: Lightning v3.1 Pro support"
---

The voice-cloning API now accepts `model: lightning-v3.1-pro` to clone onto the premium Pro pool, alongside the default `lightning-v3.1`. Pair the resulting `voice_id` with the matching TTS `model` (`lightning_v3.1` or `lightning_v3.1_pro`). The spec and model card previously stated cloning was unavailable on Pro; that was incorrect and is now fixed.
