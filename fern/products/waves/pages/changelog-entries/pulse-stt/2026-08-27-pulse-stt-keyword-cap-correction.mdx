---
title: "Pulse STT keyword boosting: session cap is 100 (docs correction)"
---

The streaming `keywords` query parameter accepts up to **100 keywords per session**.

Earlier docs and the 2026-07-22 changelog entry incorrectly stated 10,000. The runtime limit has always been 100. If your session sends more, only the first 100 entries are used.

Everything else about the parameter is unchanged: comma-separated string, `:INTENSIFIER` suffix optional, case-sensitive matching, WebSocket-only. See [Keyword Boosting](/models/documentation/speech-to-text-pulse/features/word-boosting) for the full format.
