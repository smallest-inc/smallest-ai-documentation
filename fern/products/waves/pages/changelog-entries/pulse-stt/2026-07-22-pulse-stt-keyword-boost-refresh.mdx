title: "Pulse STT keyword boosting: 100-keyword cap, softer intensifiers, cased matching"
---

Documentation refresh for the streaming `keywords` query parameter.

**Session limit is 100 keywords.**

**Intensifier guidance rewritten.** Default is `1.0`. Recommended tuning range is `1` to `3`. Values above `5` push the model into hallucination and repetition; keep keywords at `1` and only raise a specific one if it is still being missed.

**Case-sensitive matching.** Keyword matching is case-sensitive. Use the exact casing you want in the transcript (`Blackwell`, not `blackwell`).

Example strings updated: `Blackwell:1,Jensen Huang:2` replaces the older `I:20,smiling:26`.
