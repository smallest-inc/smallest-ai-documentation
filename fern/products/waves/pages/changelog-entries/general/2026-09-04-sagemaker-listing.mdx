---
title: "Self-host: Amazon SageMaker listing on AWS Marketplace"
---

Lightning v3.1 (TTS) and Pulse (STT) are now available on [AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-tf5i65efzgtco) as a SageMaker deployment. Endpoints run inside your VPC; requests never leave your AWS account.

New pages under **Self Host → Amazon SageMaker**:

- **Overview**: when SageMaker is the right fit vs Docker / Kubernetes, supported endpoint types, feature parity with the cloud API.
- **Deploy from AWS Console** and **Deploy with Terraform**: step-by-step from Marketplace subscription to `InService` endpoint (about 15 minutes).
- **Invoke the endpoint**: boto3, AWS CLI, and Smallest AI Python SDK examples for both TTS and STT, including SigV4 auth and per-request options via `CustomAttributes`.
- **Pricing**: how the Marketplace software rate combines with the AWS instance-hour rate, plus the 14-day free trial and private-offer path.
- **Cookbooks**: [batch transcription](/models/self-host/amazon-sagemaker/cookbooks/batch-transcription) from S3 via Batch Transform, and a [Lambda webhook](/models/self-host/amazon-sagemaker/cookbooks/lambda-webhook-tts) that fronts the TTS endpoint.
- **Troubleshooting**: cold-start delays, `ModelError` causes, autoscaling misconfigurations, and cost surprises.

Not shipped in the initial listing: streaming STT WebSockets, voice cloning, voice-agent orchestration. Those remain on the cloud API or Docker / Kubernetes.
