Pulse Speech-to-Text is available as an [Amazon SageMaker model package on AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-tf5i65efzgtco). Endpoints run inside your VPC; audio never leaves your AWS account.

New pages under **Self Host → Amazon SageMaker**:

- **Overview**: when SageMaker fits vs Docker / Kubernetes, current deployment-mode support matrix, instance sizing guidance, and full feature scope (all Pulse languages, diarization, PII/PCI redaction, keyword boosting).
- **Deploy from AWS Console** and **Deploy with Terraform**: step-by-step from Marketplace subscription to `InService` endpoint.
- **Invoke the endpoint**: Python (boto3) and AWS CLI examples per verified inference mode, with the full IAM policy for SigV4 auth.
- **Pricing**: how the Marketplace software rate combines with the AWS instance-hour rate.
- **Cookbook, batch transcription**: fan out an S3 audio archive through Pulse via SageMaker Batch Transform.
- **Troubleshooting**: cold-start delays, `ModelError` causes, autoscaling misconfigurations, and the delete order that stops billing.
