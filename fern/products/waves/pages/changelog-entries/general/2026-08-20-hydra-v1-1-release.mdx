---
title: "Speech-to-Speech: Hydra V1.1 released"
---

Hydra V1.1 is now served on the Waves speech-to-speech WebSocket endpoint. Switch by passing `?model=hydra-v1.1` on the query string:

```
wss://api.smallest.ai/waves/v1/s2s?model=hydra-v1.1&api_key=<SMALLEST_API_KEY>
```

The session protocol (event catalog, `session.configure` shape, tool calling, interruption handling) is identical to the original `hydra`, so switching is a one-parameter change. Connections passing `model=hydra` continue to be served by the original model.

**New voice roster.** Ten voice IDs: `zoe`, `maya`, `elena`, `ivy`, `grace`, `alex`, `aria`, `leo`, `sam`, `kai`. The V1.1 roster does not overlap with the original `hydra` roster; when you switch versions, also pick a voice from the V1.1 list. Original `hydra` voices (`wren`, `sloane`, `marlowe`, `reed`, `knox`, `tate`) are unchanged.

Full voice + version reference on the [Hydra model card](/models/model-cards/speech-to-speech/hydra). Overview + docs pages ([overview](/models/documentation/speech-to-speech-hydra/overview), [WebSocket connection](/models/documentation/speech-to-speech-hydra/web-socket-connection), [Audio I/O](/models/documentation/speech-to-speech-hydra/audio-i-o), [Managing sessions](/models/documentation/speech-to-speech-hydra/managing-sessions), [Tool calling](/models/documentation/speech-to-speech-hydra/tool-calling)) point at `?model=hydra-v1.1` in every URL example and use a V1.1 voice in the sample payloads; the `voice` field description in **managing sessions** lists both rosters and the model card remains the single source of truth for per-version voice tables.
