A voice agent on Smallest is a configured agent (prompt, voice, language, tools, knowledge base) plus a way to reach it: a phone number, a web widget, or a mobile SDK. Calls run on Pulse for speech to text and Lightning for text to speech, with the LLM turn either handled by the platform or by your own code.

## Three ways to build

<CardGroup cols={3}>
  <Card title="Dashboard" icon="browser" href="/voice-agents/quickstart">
    No code. Pick a template or start from scratch, write the prompt, choose a voice, test in the browser. A working agent in five minutes.
  </Card>
  <Card title="Agent Crew SDK" icon="fa-brands fa-python" href="/voice-agents/developer-guide/get-started/quickstart">
    Python. Your code owns the LLM turn and any application logic over a realtime WebSocket. Smallest owns speech, telephony, and turn taking.
  </Card>
  <Card title="API" icon="code" href="/api-reference/voice-agents">
    REST. Create agents, place calls, run campaigns, read analytics from your own backend. Same objects the dashboard uses.
  </Card>
</CardGroup>

Most teams start in the dashboard, then move to the API or SDK once the agent design settles. Everything configured in the dashboard is a JSON attribute on the agent, so the same guide applies to every path.

## For AI coding agents

Install the [MCP server](/voice-agents/mcp/getting-started/quick-start) and ask Claude Code, Cursor, or Codex to create, configure, and call an agent in plain English. The [Build with a coding agent](/overview/developer-tools/build-with-a-coding-agent) page has a paste ready prompt that walks a coding agent from discovery to a live test call.
